# Governance

Patchloom for VS Code is maintained by [@SebTardif](https://github.com/SebTardif).

## Roles

| Role | Scope | Who |
|------|-------|-----|
| Maintainer | Full commit, release, and moderation authority | @SebTardif |
| Contributor | Submit issues and pull requests | Anyone |

## Decision process

All design and release decisions are made by the maintainer. Contributors are encouraged to open issues for discussion before starting large PRs.

## Releases

The maintainer decides when to cut releases. There is no fixed cadence.

## Security

Security vulnerabilities should be reported through [GitHub private vulnerability reporting](https://github.com/patchloom/patchloom-vscode/security/advisories/new). See [SECURITY.md](SECURITY.md) for details.

## Changes to governance

As the project grows, governance may evolve to include additional maintainers or a steering committee. Changes to this document will be proposed via pull request.
