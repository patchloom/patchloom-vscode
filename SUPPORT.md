# Support

## Getting Help

- **Bug reports and feature requests**: [GitHub Issues](https://github.com/patchloom/patchloom-vscode/issues)
- **Security vulnerabilities**: [SECURITY.md](SECURITY.md)
- **Contributing**: [CONTRIBUTING.md](CONTRIBUTING.md)

## Before Opening an Issue

1. Search [existing issues](https://github.com/patchloom/patchloom-vscode/issues) to avoid duplicates.
2. Run `Patchloom: Show Status` and include the output in your report.
3. Include your VS Code version (`Help > About`).

## Patchloom CLI Issues

For issues with the Patchloom CLI itself (not the VS Code extension), file them at [patchloom/patchloom](https://github.com/patchloom/patchloom/issues).
